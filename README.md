# 自用linux脚本

## backup.sh

### 功能介绍

无快照功能VPS的全量备份脚本

### 说明

- 备份整个系统盘到 .img.gz 压缩文件（可放到本地或远程存储）。
- 恢复时自动写回磁盘。
- 带进度条，防止你怀疑它卡住。
- 自动检测系统盘设备名（防止误写其他盘）。

### 恢复系统

- 必须关机后进入救援模式 / 其他系统环境 执行恢复（不能在当前系统直接写自己）。
- 运行脚本选择 2，然后输入要恢复的 .img.gz 文件路径。

### 注意事项

- 备份文件大小 ≈ 系统盘容量（压缩后可能小很多）。
- 建议定期把 /root/system_backups 里的文件下载到本地。
- 恢复时必须保证目标磁盘与备份时的磁盘大小一致或更大。
